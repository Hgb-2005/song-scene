# 一歌一景 V8 · 安装与第一次创作

适用系统：Windows 10 / 11，64 位。桌面安装包包含 Python 运行环境，电脑无需安装 Python，也不需要打开终端。

## 安装与打开

1. 双击 `SongScene-v8-Windows-Setup.exe`，按提示安装到自己的用户目录，无需管理员权限。
2. 打开“一歌一景”。一个小窗口负责运行本机工作台，创作页面在默认浏览器打开。
3. 本机已有支持字幕和 H.264 编码的 FFmpeg 时会直接使用；没有时，首次打开自动从 Gyan 官方构建站下载固定版本的 FFmpeg 9.0.2（约 109 MB），校验 SHA-256 后解压到个人缓存。首次准备需要网络，以后可离线制作。下载失败会给出原因和重试入口。
4. 创作期间保持桌面小窗口开启。关闭浏览器不会丢作品，点击“打开创作工作台”可以回来。关闭小窗口会停止服务；合成中退出前会提醒。

免安装版：解压 `SongScene-v8-Windows-Portable.zip`，双击文件夹中的 `SongScene.exe`。不要只把 EXE 单独复制出去，旁边的 `_internal` 目录是必需的。

安装包目前没有代码签名证书，Windows 可能显示未知发布者。这是尚未完成正式商业分发的一项限制；无需关闭系统安全功能。源码、构建脚本与发布文件校验值可用于核对来源。

## 做第一条短片

1. 首页填歌名，可选填歌手和想表达的感觉，建立一份需求。
2. 在详情选带声音的歌曲素材，或导入本地 MP3/WAV/MP4，确定开始、结束时间。内置 10 首样片可用于练习。
3. 把歌词或段落名称逐行写下，拆成画面，再给每一段选择图片/视频。自动拆分只是平均分时长，歌词切点需要自己试听确认。
4. 在“先看一遍，再做成片”中播放预览。拖动进度条检查每句歌词、画面切换；点某段的“预览此段”可快速定位。
5. 调整当前画面的左右、上下取景，避免重要内容被竖屏裁掉。调整字幕大小、离底部距离，也可以关闭字幕。裁切按段保存，字幕设置作用于整条作品。
6. 保存方案，先导出 540 画质检查，满意后再导出 1080 成片。成片会自动放进个人片库。

预览采用浏览器原生播放，使用同一份段落时间、取景坐标和字幕设置。浏览器与 FFmpeg 的字体、换行及视频解码支持可能有差异；最终编码以导出视频为准。不支持在浏览器播放的素材会明确提示，不会用封面假装成视频效果。

## 数据放在哪里

桌面版固定保存在 `%LOCALAPPDATA%\SongScene\data`。点击桌面小窗口“打开数据文件夹”，或者页面“数据与备份”查看实际路径。程序安装目录、作品数据目录分开，安装新版、卸载程序都保留作品数据。引擎缓存位于 `%LOCALAPPDATA%\SongScene\engine`。

源码版继续默认使用项目的 `data` 文件夹，也可用 `--data-dir` 指定位置。

## 从 V7 迁移与换电脑

在旧 V7 的“数据与备份”导出完整备份 ZIP；打开 V8，导入该 ZIP，确认预览内容和冲突处理方式后恢复。旧版目录保留。V7 方案没有取景和字幕设置时，V8 会按居中取景、标准底部字幕打开。

卸载前建议导出完整备份。卸载不会删数据；如果希望彻底清理，应在确认备份可恢复后自行处理数据目录。

## 仍然需要人工完成的事

歌曲和画面由你提供；歌词时间、画面想法由你确认。不自动识别整首歌词、不联网搜素材、不自动生成视频。内置样片及其音乐、图片各自的来源和限制见 `THIRD_PARTY_NOTICES.md`，公开源码不等于获得音乐商业使用许可。
