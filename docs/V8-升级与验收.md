# V8 · 从能用的页面，到更容易上手的本机工具

## 这次改动

1. 新增 Windows 安装版与免安装桌面版，包含 Python 运行环境。启动器负责打开页面、打开数据文件夹、重复启动复用实例及退出管理。
2. 桌面数据固定存到个人目录，和程序分开；覆盖安装、卸载不会删除需求和作品。源码模式保持原来的项目 data 目录。
3. 没有兼容 FFmpeg 时，第一次打开会自动下载上游固定版本、校验 SHA-256 并准备好引擎。首次需要联网约 109 MB，以后使用缓存。发布包没有重新分发 FFmpeg 二进制。
4. 制作详情新增 9:16 实时预览：歌曲播放、画面切换、歌词叠加、拖动进度、0.1 秒微调、定位某段。
5. 每段增加左右、上下取景；整条作品可设置字幕开关、大小与离底部位置。预览和 FFmpeg 共享这些保存参数。
6. 旧 V7 方案没有新设置时采用居中取景、标准底部字幕；新设置支持保存、脏草稿保护、任务包、备份和恢复。
7. 修复窗口化程序没有控制台时，错误请求日志可能阻断错误响应的问题。桌面错误写入数据目录 desktop.log。
8. 补齐第一次创作说明和五人试用记录表，外部试用保持“未测试”，没有拿内部操作冒充真实用户反馈。

## 已验证

- Python 3.10.9 和 3.14.10 下均完整通过 14 项 Python 测试，无跳过；7 项 Node 前端契约测试通过。
- 实际合成检查左右取景输出像素、字幕参数、视频循环、540 / 1080 输出、音轨和自动归档；完整备份与旧版默认值保持兼容。
- 引擎下载哈希不符、取消、危险压缩包路径不会留下可用的半成品引擎；实例锁正常释放、可重新启动。
- 在隔离用户目录、PATH 中没有 Python/FFmpeg 的情况下安装并启动 EXE，成功自动下载、校验并启用 FFmpeg 9.0.2；三项媒体能力均就绪。
- 重复启动第二个 EXE 立即复用已有实例；实际桌面程序可打开本机工作台。首次桌面测试正常退出后端点文件移除、进程结束。
- 桌面安装版实际输出 2 秒、540×960、带音轨与字幕的 MP4；页面操作实际输出另一条 8 秒作品，并自动归档。
- 用最终安装包覆盖安装后，数据库逐字节不变；重开后找回同一份方案、成片及关联。窗口化程序的错误请求返回正常 JSON。
- 卸载测试程序后，所有记录和素材哈希保持不变；最终一次测试进程清理后，也能正常读取全部 SQLite 记录。
- 浏览器实测图片/视频切换、定位某段、字幕和取景保存后刷新保留；1366、390、320 宽度无横向溢出，正常流程控制台错误为 0。
- 167 个 HTML 编号无重复，模块与必需素材检查通过。原十条高清视频和十条预览视频未修改。

以上为当前 Windows 电脑与 Chromium 的内部验证，不代表多台真实电脑或真机手机测试，也不是五位外部用户的验收结果。

## 仍有边界

- 安装包未代码签名，仍需不同电脑的安装/防护软件兼容性验证。
- 浏览器快速预览与 FFmpeg 在字体、换行、解码支持上可能有差异；最终成片应先用 540 输出确认。
- 图片保持静态，段落使用直接切换；不包含转场特效、自动歌词识别、自动生成画面。
- 第一次下载引擎受网络影响，失败可重试；后续可离线制作。
- 五人首次使用测试需项目主人实际邀请参与者执行，表格见同目录说明。

Windows 包使用官方 CPython 3.14.10、PyInstaller 6.22.3、Inno Setup 7.1.1 构建；许可证随包提供，构建脚本见 tools/build_windows.py。
