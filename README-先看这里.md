# 一歌一景 V7 · 本机歌曲短片工作台

从三项轻量需求开始，继续选歌曲片段、逐句配画面、安排制作，最后把完成的作品归档回来。暖白与深绿界面，个人本机使用，无云账号、无付费模型调用。

## 启动

Windows双击 **启动工作台.bat**。需要Python 3.10或更新版本，不需要pip、npm安装。系统中安装FFmpeg与FFprobe后可识别音视频、自动截封面和合成成片；没有它们时，需求与备份管理仍可使用。

```text
python app.py --open
```

默认地址：`http://127.0.0.1:8866/index.html`。保持服务窗口开启。端口被旧版占用时请先关闭旧版服务，或使用 `python app.py --port 8867 --open`。V7的磁盘记录与浏览器、端口无关，启动同一程序目录仍会读取同一data目录。

V7需要本机服务，直接双击HTML会显示启动说明。它包含磁盘数据库和媒体处理接口，不能按纯静态网页直接发布。

## 五个工作区

### 开始创作

只填歌名、歌手 / 版本、想表达的感觉。歌名必填，其他选填。首页草稿自动写入工作目录。保存后进入具体需求，继续安排制作。点击样片“以此为参考”可关联参考作品。

### 制作看板

需求分为待规划、安排画面、制作中、已完成。前三种状态可以自行调整；标记完成需要真实关联成片。归档是软删除，可以从已归档列表恢复，素材不删除。

每份需求里有三个步骤：

1. **选择歌曲片段**：导入本地歌曲 / 带声音的视频，或使用附带样片练习。可试听、拖动起终点、用当前播放位置标记时间。成片片段限制0.2—120秒。
2. **安排歌词与画面**：每行一段歌词或画面名称，先平均分配时长，再试听调整；每段可选本地图片 / 视频，填写画面想法和素材起点。最多60段，每段歌词最多120字。使用同一参考样片音轨时，可带入该样片原有歌词时间；更换声音后需要自行校准。
3. **完成与归档**：可以导入通过其他流程完成的视频，也可以按当前方案在本机合成。合成完成会自动注册到个人片库，并把需求标记为完成。

编辑方案后请点击“保存方案”。离开未保存内容时会提示，并尽量保留浏览器草稿。浏览器草稿仅用于补救，不等于已存入磁盘或已包含在完整备份。多窗口同时编辑时，旧版本保存会被拦截，防止覆盖新内容。

**制作任务包**会导出JSON方案、Markdown说明、SRT歌词时间轴和用到的素材，方便继续人工制作。

### 灵感片库

保留原有十条样片，并支持导入第十一条及更多个人作品。无需改代码。可填写歌名、实际歌手、翻唱信息、心情、封面和关联需求。未选封面时会尝试截取第一帧。支持情绪筛选、搜索、收藏、最近观看、歌词定位和视频下载。

### 我的素材

可导入MP4、MOV、WebM、MKV、MP3、WAV、M4A、FLAC、OGG、AAC、JPG、PNG、WebP。单文件上限1GB，音视频最长两小时，图片宽高不超过10000像素。每次批量最多10个。导入是复制，不会移动或覆盖原文件。相同内容会复用已有文件。

### 数据与备份

- 记录保存于 `data/workspace.sqlite3`，导入和生成的素材在 `data/assets/`。
- 每次保存需求或作品，保留最近30份记录快照于 `data/backups/`。快照只保存记录，不复制媒体。
- 完整ZIP备份包括需求、画面方案、当前已保存首页草稿、收藏、个人作品和导入媒体。内置样片随程序包提供，不重复放进备份。
- 恢复前会展示需求、作品、素材数量和同编号冲突。可以保留本机、使用较新版本、使用备份版本，或将冲突的需求与作品另存一份。
- 支持导入V6导出的JSON。首次在同一浏览器、原本机地址打开时，也会尝试迁移旧版浏览器中仍在的记录，旧版记录不删除。
- 备份上限2GB，解压内容上限4GB、10000条文件。恢复完整备份到另一台电脑时，应使用同样包含所需内置参考视频的程序包。

## 本机合成的实际能力

合成使用FFmpeg：把用户选择的图片 / 视频按明确时间轴裁切、缩放到9:16并连接，配入选定的歌曲片段，可叠加歌词，输出540×960或1080×1920 MP4。图片保持静态，视频按设定素材起点播放，不足时循环。使用居中裁切，请自行确认主体位置适合竖屏。

进度来自实际合成任务；可以取消或失败后重试。合成过程中方案会锁定，避免任务读到一半被修改。服务意外停止后，下次启动会标记上次任务中断，方案仍保留。

它不根据歌名联网下载音乐，不自动找素材，不自动判断歌词演唱时间，不调用AI生成新画面。歌词与画面是否合适，由你确认。原十条视频保持原样。

## 三种交付

- 完整可播放包：含程序、十条高清样片与十条轻量预览。
- 轻量可播放包：含程序与十条预览，内置样片保存和练习使用预览文件。
- 页面源码包：含程序和封面，不含MP4。仍可导入自己的音乐与素材、管理需求和合成作品。

发给别人或更新程序前，先导出完整备份；复制 / 发布源码时不要带上私人data目录。Git忽略与打包工具已默认排除该目录。没有替你创建GitHub仓库或对外发布。
